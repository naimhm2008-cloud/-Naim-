# Samu AI 🤖💕 — আপনার ব্যক্তিগত ভয়েস অ্যাসিস্ট্যান্ট

Android Studio প্রজেক্ট (Java)। পুরো অ্যাপটি **কোটলিন ছাড়া শুধু জাভায়** লেখা।

## কীভাবে চালাবেন

1. এই রিপোর কোড **Download ZIP** করে আনজিপ করুন (অথবা clone করুন)।
2. Android Studio (Hedgehog/Iguana বা নতুন) খুলে **File > Open** দিয়ে প্রজেক্ট ফোল্ডারটি খুলুন।
3. Gradle sync শেষ হলে **Run** চাপুন (প্রথমবার Gradle 8.7 + SDK 34 ডাউনলোড হবে)।

> যদি sync জিজ্ঞেস করে, Gradle JDK হিসেবে **Embedded JDK (17)** সিলেক্ট করুন।

## ফিচারসমূহ

### ৫টি ট্যাব
1. **হোম** — অ্যানিমেটেড রোবট-মেয়ে Samu (চোখের পলক ফেলে, কথা বলার সময় মুখ নড়ে, শোনার সময় গ্লো করে)
2. **চ্যাট** — লিখে কথা বলা, বাংলা/ইংরেজি উত্তর + ভয়েস
3. **পারমিশন** — ২৪টি পারমিশন আলাদা আলাদা, স্টেটাস + ১ ট্যাপে রিকোয়েস্ট
4. **আইকন** — গ্যালারির যেকোনো ছবি বা ইমোজি/স্টিকার দিয়ে ভাসমান আইকন, ৬ রকম আকৃতি
5. **সেটিংস** — Gemini API key, বিশেষ নাম, বসের পিক, ইমার্জেন্সি নম্বর, ভয়েস গতি/গলা, অ্যাপ লক, ব্যাকআপ

### ভয়েস লক (২ ডাকের নিয়ম)
- **"Hey Samu"** → শুধু কথা। কাজ চাইলে বলবে: *"বসের অনুমতি ছাড়া পাবো না"*
- **বিশেষ নাম** (সেটিংসে যেকোনো সময় বদলানো যায়) → সামনের ক্যামেরা ১-২ সেকেন্ড চালু হয়ে অফলাইন ML Kit ফেস-চেক করে। বস হলে ফুল কন্ট্রোল, না হলে: *"আপনি আমার বস না"*

### ফোন কন্ট্রোল
অফলাইন: অ্যাপ খোলা/বন্ধ, কল, SMS, অ্যালার্ম, টাইমার, টর্চ, ওয়াইফাই/ব্লুটুথ প্যানেল, গান, ভলিউম, ব্রাইটনেস, স্ক্রিনশট, স্ক্রিন লক, DND
অনলাইন (Gemini key দিলে): প্রশ্নের উত্তর, অনুবাদ, গল্প, পড়াশোনা + আবহাওয়া (Open-Meteo, key ছাড়া ফ্রি)

### সবসময় অ্যাক্টিভ
- ফোরগ্রাউন্ড সার্ভিস + WakeLock → স্ক্রিন Off থাকলেও "Hey Samu" শোনে
- স্ক্রিন Off হলে লো-পাওয়ার মোড, ব্যাটারি ১৫%-এর নিচে গেলে স্লিপ মোড
- Restart দিলে Boot Receiver দিয়ে নিজে থেকে চালু

### ইমার্জেন্সি মোড
"বাঁচাও" / "Help" বললেই (ফেস চেক ছাড়াই) প্রিসেট নম্বরে অটো কল + লোকেশন লিংকসহ SMS

### অ্যাপ লক
নির্বাচিত অ্যাপ অন্য কেউ খুললে Samu ব্লক করে দেয়; বস ফেস-ভেরিফাই হলে ৩০ সেকেন্ডের জন্য খোলা থাকে

### ব্যাকআপ
বিশেষ নাম, বসের পিক, আইকন, অ্যাপ-লক তালিকা — সব Downloads-এ লোকাল ব্যাকআপ (কোথাও আপলোড হয় না), অ্যাপ ডিলিট হলেও রিস্টোর করা যায়

### প্রাইভেসি
ভয়েস, ছবি, ব্যাকআপ — সব ফোনেই থাকে। ফেস-চেক সম্পূর্ণ অফলাইন (ML Kit)। ইন্টারনেট শুধু Gemini উত্তর ও আবহাওয়ার জন্য।

## গুরুত্বপূর্ণ নোট

- **Wake word**: অ্যান্ড্রয়েডের বিল্ট-ইন (Google) স্পিচ রিকগনিজার ব্যবহার হয়েছে — এটা অনেক ফোনে অফলাইনেও কাজ করে। আরও নিখুঁত হট-ওয়ার্ডের জন্য পরে Picovoice Porcupine (ফ্রি টিয়ার) যোগ করা যাবে।
- **নতুন অ্যান্ড্রয়েড (10+) সীমাবদ্ধতা**: ওয়াইফাই/ব্লুটুথ সরাসরি টগল করা গেলে প্যানেল খুলে দেয় — এটা গুগলের সিকিউরিটি নিয়ম, সব অ্যাসিস্ট্যান্টের জন্যই একই।
- **Gemini key ফ্রি পাবেন**: [aistudio.google.com](https://aistudio.google.com/apikey) — সেটিংস ট্যাবে পেস্ট করুন।
- বাংলা ভয়েস ইনপুট ভালো কাজ করতে ফোনে **Google এর বাংলা অফলাইন স্পিচ ডেটা** ডাউনলোড করে নিন (Settings > Google > Offline speech recognition)।

## প্রজেক্ট স্ট্রাকচার

```
app/src/main/java/com/samu/ai/
├── App.java                  # নোটিফিকেশন চ্যানেল
├── MainActivity.java         # ৫ ট্যাব
├── SettingsStore.java        # সব সেটিংস (ফোনেই সেভ)
├── ai/                       # SamuBrain, GeminiClient, WeatherClient
├── actions/                  # ফোন কন্ট্রোল, কন্টাক্ট/অ্যাপ লুকআপ
├── speech/                   # WakeWordListener, CommandParser (বাংলা+ইংরেজি)
├── service/                  # ফোরগ্রাউন্ড, ভাসমান আইকন, অ্যাক্সেসিবিলিটি
├── face/                     # বস ফেস-ভেরিফিকেশন (ML Kit, অফলাইন)
├── emergency/                # ইমার্জেন্সি কল + SMS + লোকেশন
├── lock/                     # অ্যাপ লক
├── backup/                   # লোকাল ব্যাকআপ (MediaStore/Downloads)
├── receiver/ admin/          # বুট অটো-স্টার্ট, ডিভাইস অ্যাডমিন
├── ui/                       # ফ্র্যাগমেন্ট + অ্যাডাপ্টার
└── view/                     # SamuAvatarView (অ্যানিমেটেড রোবট-মেয়ে)
```
